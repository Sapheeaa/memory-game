# Memory Game

## Описание проекта
**Memory Game** — это классическая игра на развитие памяти и концентрации, реализованная с помощью чистого JavaScript, HTML5 и CSS3 (Vanilla JS) без использования сторонних фреймворков и библиотек. 

Цель игры — найти все пары одинаковых карточек за минимальное количество ходов.

## Основной функционал
- Динамическая генерация игрового поля и карточек на основе данных из `cards.json`.
- Переворот карточек при клике и проверка на совпадение (пара/не пара).
- Блокировка игрового поля во время показа несовпавших карточек (таймер задержки).
- Подсчет текущих ходов и найденных пар в реальном времени.
- Модальное окно победы при успешном нахождении всех 8 пар с отображением статистики и возможностью рестарта.
- Кнопка «New Game» для сброса и перезапуска игры в любой момент.
- Поддержка закрытия модального окна клавишей `Escape`.

## Технологии
- **HTML5** (структурированная разметка)
- **CSS3** (стилизация, Flexbox, анимации переворота карточек)
- **JavaScript (ES6+)** (управление состоянием, асинхронность, чистый DOM-монтаж)

  ## Как играть

1. **Цель игры**: Найти все пары одинаковых карточек за наименьшее количество ходов.
2. **Игровой процесс**: 
   - Перед началом игры карточки перемешиваются и раскладываются на поле рубашкой вверх.
   - Кликайте по карточкам, чтобы переворачивать их по две за один ход.
   - Если карточки совпали — они остаются открытыми.
   - Если не совпали — они ненадолго останутся видимыми, чтобы вы их запомнили, а затем снова переворачиваются рубашкой вверх.
3. **Победа**: Игра заканчивается, когда открыты все 8 пар. После этого появится поздравительное модальное окно с вашей статистикой.
4. **Управление**:
   - Кнопка **«New Game»** в шапке сайта позволяет в любой момент сбросить текущий прогресс и начать игру заново с новым перемешиванием.
   - Модальное окно победы можно закрыть кнопкой **«Close»** или нажатием клавиши **Escape**.
